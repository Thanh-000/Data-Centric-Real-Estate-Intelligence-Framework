# Final Report

This folder contains the LaTeX final report for the INS3254 project.

Build locally with a TeX distribution:

```bash
cd report
pdflatex main.tex
pdflatex main.tex
```

The report references figures generated by the project pipeline under `../outputs/figures/`.
References are embedded directly in `main.tex`, so this report does not require a separate BibTeX file.
Run the pipeline before compiling if those figures are missing:

```bash
python ../scripts/run_pipeline.py
python ../scripts/evaluate_synthetic_anomalies.py
python build_report_figures.py
```

If the final submission requires named individual contributions, update the contribution table in `main.tex` before export.
